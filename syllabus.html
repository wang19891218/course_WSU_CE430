Course Description

Catalog Description

Analysis of Indeterminate Structures. Stiffness methods for the analysis of trusses, beams, and frames; matrix models; and computer applications.

Expanded Description

This course is an extension of concepts introduced in CE 330. Recall that structural design involved an inequality dealing with capacity versus demand, with factors on each to enforce a desired level of safety. If you are specializing in structural engineering, you are no doubt pursuing courses in steel, reinforced concrete, prestressed concrete, and/or timber design. In those courses, the emphasis is on choosing structural systems to have a desired capacity. Here, we focus on the other side of the design inequality, namely a determination of demand. That is, for a given structural system, subjected to a given pattern of loads, we must build a mathematical model by which we may compute items such as member forces (often consisting of axial force, shear, and bending moment), reaction forces at supports, and selected displacement values.

Hand methods of structural analysis are tedious to apply to all but the simplest of structures. Nowadays, practical structural modeling is almost always done on the computer using software based on the Stiffness Method. To be effective structural engineers, we must have an understanding of the physical concepts and numerical methods involved in this type of structural modeling. Also, the material covered in this class is a preview and a subset of the more general Finite Element Method.

In this class, the Stiffness Method is first introduced through the classical Slope-Deflection Method for beams. Then, we transition into the more general matrix methods of structural analysis for beams, frames, and trusses. If time permits, we will also touch on the more advanced topics of second-order (or P-Δ) analysis, stability, and inelastic analysis. The emphasis is on understanding of the method and the practical application of it.

Student Learning Outcomes

  • Ability to explain structural behavior through the development of classical analysis techniques based on the Stiffness Method for indeterminate analysis.
  • Ability to use modern computer-based methods of structural modeling through:
    1. Understanding of how structural equations of equilibrium and compatibility are put in a matrix format.
    2. Implementation of the procedures that are used to obtain solutions (i.e., the algorithms).
    3. Practice in the solution of structural analysis problems (with proper interpretation of results) using software.
  • Ability to recognize the algorithm implemented in commercial structural analysis software, and to verify its results independently by hand and by code.

Homework

This class will have 12 homework assignments to reinforce course material. Due time is 23:59 on the date specified, unless otherwise noted. The lowest two homework grades are dropped; the highest 10 are used to compute the final grade.

The two dropped scores are the course's built-in allowance for illness, travel, workload spikes, and simple bad weeks, so extensions are not normally granted and none is needed to stay in good standing. If something larger happens — an extended illness, a family emergency, a documented accommodation — contact me as early as you can and we will make a reasonable arrangement.

Homework submission: write neatly and legibly in pencil on engineering paper, scan, and submit a single PDF on Canvas (unless otherwise noted). Computation problems should be presented as a synthesized typed report using professional technical writing.

Coding Homeworks and the ce430 Package

Five of the twelve homeworks are coding homeworks. Together they build ce430, a small Python package for frame analysis, one stage per homework, and each stage is something you have already done by hand in class before you are asked to code it:

  • HW4 — matrix algebra in Python; package setup.
  • HW6 — member stiffness matrix and coordinate transformation.
  • HW7 — assembly, supports, solution, member end forces.
  • HW10 — member loads and fixed-end forces.
  • HW12 — geometric stiffness and the critical load.

I supply the package skeleton: the module layout, the function signatures, docstrings that specify exactly what each function must do, and an automated test for each one. You fill in the bodies. When all five are done you have a working analysis program that you wrote, and in the last two weeks we run a complete building frame through it and check it against OpenSeesPy.

You are never blocked by your own earlier work. Every coding homework ships with a base template. You may build on your own code from the previous stage, and I encourage you to, but if your version of an earlier step is incomplete or incorrect, switch that one import to my reference implementation, which is released after each deadline, and continue with the current week's material.
